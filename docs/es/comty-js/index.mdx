`comty.js` es el cliente JavaScript oficial de la API de Comty.

Incluye un cliente HTTP con pipeline de autenticación automático, un gestor de autenticación autónomo, un motor de almacenamiento agnóstico, un gestor de websockets auto-gestionado y wrappers tipados de los endpoints del backend.

## Instalación

```bash
pnpm add comty.js
```

## Inicio rápido

```ts
import { authManager } from "comty.js"
import UsersModel from "comty.js/endpoints/user"

// carga la sesión persistida y arranca el auto refresh
await authManager.start()

const user = await UsersModel.self()
```

## Arquitectura

### Núcleo

| Módulo | Descripción |
| --- | --- |
| [Client](core/client) | Cliente HTTP y pipeline de peticiones |
| [Session](core/session) | Sesión actual y acceso a los tokens |
| [Storage](core/storage) | Motor de almacenamiento agnóstico (memoria, cookies, expo secure store) |
| [Authentication](core/authentication) | Gestor de autenticación autónomo, auto refresh y store de estado |
| [Realtime](core/realtime) | Gestor de websockets auto-gestionado |

### Endpoints

Wrappers tipados de los endpoints del backend, un singleton por dominio. Ver [Endpoints](endpoints).

### Addons

Registra addons de terceros que extienden los resultados de los endpoints. Ver [Addons](addons).

## Imports

El paquete expone un mapa `exports`, por lo que están disponibles tanto el barrel como los subpaths individuales:

```ts
import { Client, session, authManager } from "comty.js"

import client from "comty.js/client"
import { authManager } from "comty.js/auth"
import useAuth from "comty.js/auth/use"
import WebsocketManager from "comty.js/realtime"
import UsersModel from "comty.js/endpoints/user"
import use from "comty.js/hooks/use"
import measurePing from "comty.js/utils/measurePing"
```
