## Search

La clase `Search` proporciona un método estático para realizar búsquedas usando la API de Comty.

**Resumen de la clase:**

La clase `Search` encapsula la funcionalidad de búsqueda, permitiendo buscar contenido usando palabras clave y parámetros opcionales. También soporta addons externos para extender la funcionalidad de búsqueda.

### Métodos estáticos

*   `search(keywords, params, returnFields)`

Realiza una búsqueda usando las palabras clave y los parámetros opcionales proporcionados.

    *   `keywords`: *string* Las palabras clave a buscar.
    *   `params`: *object, opcional* Parámetros opcionales para la búsqueda.
        *   `limit`: *number, opcional* El número máximo de resultados a devolver, por defecto: 50.
        *   `offset`: *number, opcional* El offset desde el que empezar la búsqueda, por defecto: 0.
        *   `sort`: *string, opcional* El orden de clasificación "asc" o "desc", por defecto: "desc".
        *   `fields`: *array, opcional* Un array de campos a devolver en los resultados. Si está vacío, se devolverán todos los campos.
    *   `returnFields`: *array, opcional* Un array de campos a devolver en los resultados. Si está vacío, se devolverán todos los campos.
    *   Devuelve: Una promise que resuelve con los resultados de la búsqueda.

### Referencia de la API

*   `search(keywords: string, params: object, returnFields: array)`: Promise[object] - Realiza una búsqueda usando las palabras clave y los parámetros opcionales proporcionados.
