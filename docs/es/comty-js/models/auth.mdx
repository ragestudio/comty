## AuthModel

La clase `AuthModel` proporciona métodos estáticos para gestionar la autenticación de usuarios, el registro y la gestión de sesiones.

**Resumen de la clase:**

La clase `AuthModel` proporciona métodos para el inicio y cierre de sesión, el registro, la verificación de tokens, la validación de nombres de usuario, la gestión de contraseñas y la activación/desactivación de cuentas.

### Métodos

*   `login(payload, callback)`
    *   Gestiona de forma asíncrona el proceso de inicio de sesión.
    *   Parámetros:
        *   `payload`: *object* Un objeto que contiene el nombre de usuario, la contraseña y el código MFA si es necesario.
        *   `callback`: *function, opcional* Una función de callback para gestionar acciones posteriores tras el login.
    *   Devuelve: *Promise[object | boolean]* Una Promise que resuelve con los datos de la respuesta si el login es correcto. Devuelve `false` si se requiere MFA.

*   `logout()`
    *   Cierra de forma asíncrona la sesión del usuario destruyendo la sesión actual y emitiendo un evento de logout correcto.
    *   Devuelve: *Promise[void]* Una Promise que resuelve cuando termina el proceso de logout.

*   `register(payload)`
    *   Registra un nuevo usuario con el payload proporcionado.
    *   Parámetros:
        *   `payload`: *object* Un objeto con la información del usuario: nombre de usuario, contraseña, email, tos.
    *   Devuelve: *Promise[object]* Una Promise que resuelve con los datos de la respuesta si el registro es correcto.
    *   Lanza: Error si el registro falla.

*   `authToken(token)`
    *   Verifica el token indicado y devuelve los datos de usuario asociados.
    *   Parámetros:
        *   `token`: *string, opcional* El token a verificar. Si no se proporciona, se usa el token almacenado.
    *   Devuelve: *Promise[object]* Una Promise que resuelve con los datos de usuario si el token es válido.
    *   Lanza: Error si hubo un problema con la petición.

*   `usernameValidation(username)`
    *   Valida la existencia de un nombre de usuario.
    *   Parámetros:
        *   `username`: *string* El nombre de usuario a validar.
    *   Devuelve: *Promise[boolean | object]* Una Promise que resuelve con los datos de la respuesta si la validación es correcta, o `false` si hubo un error.
    *   Lanza: Error si la validación falla.

*   `availability(payload)`
    *   Recupera la disponibilidad de un nombre de usuario y un email.
    *   Parámetros:
        *   `payload`: *object* Un objeto con el nombre de usuario y el email para comprobar su disponibilidad.
    *   Devuelve: *Promise[object | boolean]* Una Promise que resuelve con los datos de disponibilidad si es correcto, o `false` si ocurrió un error.

*   `changePassword(payload)`
    *   Cambia la contraseña del usuario.
    *   Parámetros:
        *   `payload`: *object* Un objeto con currentPassword, newPassword y code opcional.
    *   Devuelve: *Promise[object]* La respuesta de datos tras cambiar la contraseña.

*   `activateAccount(user_id, code)`
    *   Activa la cuenta de un usuario con el código de activación proporcionado.
    *   Parámetros:
        *   `user_id`: *string* El ID del usuario a activar.
        *   `code`: *string* El código de activación enviado al email del usuario.
    *   Devuelve: *Promise[object]* Una Promise que resuelve con los datos de la respuesta tras la activación.
    *   Lanza: Error si el proceso de activación falla.

*   `resendActivationCode(user_id)`
    *   Reenvía el código de activación al usuario.
    *   Parámetros:
        *   `user_id`: *string* El ID del usuario al que reenviar el código de activación.
    *   Devuelve: *Promise[object]* Una Promise que resuelve con los datos de la respuesta tras enviar el código de activación.
    *   Lanza: Error si el proceso de reenvío falla.

*   `disableAccount(options)`
    *   Desactiva la cuenta del usuario.
    *   Parámetros:
        *   `options`: *object, opcional* Un objeto con opciones para desactivar la cuenta.
            *   `confirm`: *boolean* Confirmación para desactivar la cuenta.
    *   Devuelve: *Promise[object]* Una Promise que resuelve con los datos de la respuesta tras desactivar la cuenta.

*   `recoverPassword(usernameOrEmail)`
    *   Recupera la contraseña de una cuenta de usuario.
    *   Parámetros:
        *   `usernameOrEmail`: *string* El nombre de usuario o email asociado a la cuenta a recuperar.
    *   Devuelve: *Promise[object]* Una Promise que resuelve con los datos de la respuesta tras iniciar el proceso de recuperación de contraseña.

### Referencia de la API

*   `login(payload: object, callback: function | undefined)`: *Promise[object | boolean]* - Gestiona de forma asíncrona el proceso de login.
*   `logout()`: *Promise[void]* - Cierra de forma asíncrona la sesión del usuario.
*   `register(payload: object)`: *Promise[object]* - Registra un nuevo usuario.
*   `authToken(token: string | undefined)`: *Promise[object]* - Verifica el token indicado.
*   `usernameValidation(username: string)`: *Promise[boolean | object]* - Valida la existencia de un nombre de usuario.
*   `availability(payload: object)`: *Promise[object | boolean]* - Recupera la disponibilidad de un nombre de usuario y un email.
*   `changePassword(payload: object)`: *Promise[object]* - Cambia la contraseña del usuario.
*   `activateAccount(user_id: string, code: string)`: *Promise[object]* - Activa la cuenta de un usuario.
*   `resendActivationCode(user_id: string)`: *Promise[object]* - Reenvía el código de activación.
*   `disableAccount(options: object | undefined)`: *Promise[object]* - Desactiva la cuenta del usuario.
*   `recoverPassword(usernameOrEmail: string)`: *Promise[object]* - Recupera la contraseña de una cuenta de usuario.
