## TidalService

La clase `TidalService` proporciona métodos estáticos para enlazar e interactuar con el servicio de Tidal.

**Resumen de la clase:**

La clase `TidalService` ofrece métodos para enlazar y desenlazar cuentas, comprobar el estado de la conexión y recuperar datos del servicio de Tidal.

### Propiedades estáticas

*   `api_instance`: Devuelve la instancia de la API para el servicio de Tidal.

### Métodos estáticos

*   `linkAccount()`

Abre una nueva pestaña para enlazar la cuenta de Tidal del usuario.

    *   Devuelve: Una Promise que resuelve con los datos del enlace.
    *   Lanza: Error si no se ejecuta en un entorno de navegador

*   `unlinkAccount()`

Desenlaza la cuenta de Tidal del usuario.

    *   Devuelve: Una Promise que resuelve con los datos del desenlace.
    *   Lanza: Error si no se ejecuta en un entorno de navegador

*   `isActive()`

Comprueba si la cuenta de Tidal del usuario está enlazada.

    *   Devuelve: Una Promise que resuelve con un booleano indicando si la cuenta está enlazada.
    *   Lanza: Error si no se ejecuta en un entorno de navegador

*   `getCurrentUser()`

Recupera el usuario actual de Tidal.

    *   Devuelve: Una Promise que resuelve con los datos del usuario actual.

*   `getPlaybackUrl(track_id)`

Recupera la URL de reproducción para un ID de pista de Tidal dado.

    *   `track_id`: *string* El ID de la pista de Tidal.
    *   Devuelve: Una Promise que resuelve con los datos de la URL de reproducción.

*   `getTrackManifest(track_id)`

Recupera el manifiesto de la pista para un ID de pista de Tidal dado.

    *   `track_id`: *string* El ID de la pista de Tidal.
    *   Devuelve: Una Promise que resuelve con los datos del manifiesto de la pista.

*   `getMyFavoriteTracks({ limit = 50, offset = 0 } = {})`

Recupera las pistas favoritas del usuario en Tidal.

    *   `{ limit, offset }`: *object, opcional* Un objeto que contiene parámetros de paginación.
        *   `limit`: *number* El número máximo de pistas a recuperar.
        *   `offset`: *number* El offset desde el que empezar a recuperar.
    *   Devuelve: Una Promise que resuelve con los datos de las pistas favoritas.

*   `getMyFavoritePlaylists({ limit = 50, offset = 0 } = {})`

Recupera las playlists favoritas del usuario en Tidal.

    *   `{ limit, offset }`: *object, opcional* Un objeto que contiene parámetros de paginación.
        *   `limit`: *number* El número máximo de playlists a recuperar.
        *   `offset`: *number* El offset desde el que empezar a recuperar.
    *   Devuelve: Una Promise que resuelve con los datos de las playlists favoritas.

*   `getPlaylistData({ playlist_id, resolve_items = false, limit = 50, offset = 0 })`

Recupera los datos de una playlist de Tidal.

    *   `playlist_id`: *string* El ID de la playlist de Tidal.
    *   `{ resolve_items, limit, offset }`: *object, opcional* Un objeto que contiene opciones de la playlist.
        *   `resolve_items`: *boolean* Si resolver los elementos de la playlist.
        *   `limit`: *number* El número máximo de elementos a recuperar.
        *   `offset`: *number* El offset desde el que empezar a recuperar.
    *   Devuelve: Una Promise que resuelve con los datos de la playlist.

*   `getPlaylistItems({ playlist_id, resolve_items = false, limit = 50, offset = 0 })`

Recupera los elementos de una playlist de Tidal.

    *   `playlist_id`: *string* El ID de la playlist de Tidal.
    *   `{ resolve_items, limit, offset }`: *object, opcional* Un objeto que contiene opciones de la playlist.
        *   `resolve_items`: *boolean* Si resolver los elementos de la playlist.
        *   `limit`: *number* El número máximo de elementos a recuperar.
        *   `offset`: *number* El offset desde el que empezar a recuperar.
    *   Devuelve: Una Promise que resuelve con los datos de los elementos de la playlist.

*   `toggleTrackLike({ track_id, to })`

Alterna el me gusta de una pista de Tidal.

    *   `track_id`: *string* El ID de la pista de Tidal.
    *   `to`: *boolean* Si dar me gusta o quitarlo a la pista.
    *   Devuelve: Una Promise que resuelve con los datos de la respuesta.
