## E2EModel

La clase `E2EModel` proporciona métodos estáticos para gestionar las claves de cifrado de extremo a extremo.

**Resumen de la clase:**

La clase `E2EModel` ofrece métodos para recuperar y actualizar pares de claves.

### Métodos estáticos

*   `getKeyPair()`

Recupera el par de claves del usuario actual.

    *   Devuelve: Una Promise que resuelve con los datos del par de claves.

*   `updateKeyPair(str, { imSure = false } = {})`

Actualiza el par de claves del usuario actual.

    *   `str`: *string* El nuevo par de claves, codificado como string.
    *   `{ imSure = false }`: *object, opcional* Opciones para la actualización.
        *   `imSure`: *boolean, opcional* Confirmación para actualizar el par de claves. Debe establecerse a `true` para continuar.
    *   Devuelve: Una Promise que resuelve con los datos del par de claves actualizado.
    *   Lanza: Error si falta la confirmación.
