## EventsModel

La clase `EventsModel` proporciona métodos estáticos para recuperar datos de eventos.

**Resumen de la clase:**

La clase `EventsModel` ofrece métodos para recuperar eventos destacados y datos de un evento concreto.

### Métodos estáticos

*   `getFeatured()`

Recupera los eventos destacados.

    *   Devuelve: Una Promise que resuelve con los datos de los eventos destacados.

*   `data(id)`

Recupera los datos de un evento concreto.

    *   `id`: *string* El ID del evento.
    *   Devuelve: Una Promise que resuelve con los datos del evento.
