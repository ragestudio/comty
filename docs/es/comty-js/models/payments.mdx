## PaymentsModel

La clase `PaymentsModel` proporciona métodos estáticos para interactuar con la información de pagos.

**Resumen de la clase:**

La clase `PaymentsModel` ofrece métodos para recuperar datos de pago.

### Métodos estáticos

*   `fetchBalance()`

Obtiene el saldo actual.

    *   Devuelve: Una promise que resuelve con los datos del saldo recibidos del servidor.
