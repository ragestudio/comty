## ChatsService

La clase `ChatsService` proporciona métodos estáticos para interactuar con los datos de chats.

**Resumen de la clase:**

La clase `ChatsService` ofrece métodos para recuperar el historial de chats y los chats recientes de un usuario.

### Métodos estáticos

*   `getChatHistory(chat_id)`

Recupera el historial de chats para un ID de chat dado.

    *   `chat_id`: *string* El ID del chat.
    *   Devuelve: Una Promise que resuelve con los datos del historial de chats.
    *   Lanza: Error si no se proporciona el chat_id.

*   `getRecentChats()`

Recupera los chats recientes del usuario actual.

    *   Devuelve: Una Promise que resuelve con los datos del historial de chats.
