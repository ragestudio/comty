## MusicModel

La clase `MusicModel` proporciona métodos estáticos para interactuar con datos relacionados con la música. Encapsula varios getters y setters para pistas, lanzamientos, gestión de la biblioteca y funciones de búsqueda.

**Resumen de la clase:**

La clase `MusicModel` actúa como una fachada, ofreciendo una interfaz simplificada para acceder y manipular los datos de música a través de sus clases anidadas `Getters` y `Setters`.

### Propiedades estáticas

*   `Getters`: Un objeto que contiene métodos getter estáticos para recuperar datos de música.
*   `Setters`: Un objeto que contiene métodos setter estáticos para modificar datos de música.

### Métodos relacionados con pistas

*   `getAllTracks( { user_id, limit, page } )`
    *   Recupera las pistas de un usuario dado.
    *   Parámetros:
        *   `user_id`: *String* El ID del usuario.
        *   `limit`: *Number* El número de pistas a recuperar por página.
        *   `page`: *Number* El número de página a recuperar.
    *   Devuelve: *Promise[object]*

*   `getTrackData(id: String, options: Object)`
    *   Recupera los datos de una pista concreta.
    *   Parámetros:
        *   `id`: *String* El ID de la pista.
        *   `options`: *Object* Opciones adicionales para la petición.
    *   Devuelve: *Promise[object]*

*   `putTrack(track)`
    *   Crea/actualiza una pista.
    *   Parámetros:
        *   `track`: *Object* El objeto de pista a crear/actualizar.
    *   Devuelve: *Promise[object]*

### Métodos relacionados con la letra

*   `getTrackLyrics(id: String, options = { preferTranslation: false })`
    *   Recupera la letra de una pista concreta.
    *   Parámetros:
        *   `id`: *String* El ID de la pista.
        *   `options`: *Object*
            *   `preferTranslation`: *Boolean* Si es true, intenta recuperar la letra en el idioma preferido del usuario.
    *   Devuelve: *Promise[object]*

*   `putTrackLyrics(track_id, data)`
    *   Actualiza la letra de una pista concreta.
    *   Parámetros:
        *   `track_id`: *String* El ID de la pista.
        *   `data`: *Object* Los datos de la letra a actualizar.
    *   Devuelve: *Promise[object]*

### Métodos relacionados con lanzamientos

*   `getMyReleases({ limit, offset, keywords })`
    *   Recupera los lanzamientos del usuario.
    *   Parámetros:
        *   `limit`: *Number* El número de lanzamientos a recuperar.
        *   `offset`: *Number* El offset desde el que empezar a recuperar.
        *   `keywords`: *String* Palabras clave a buscar.
    *   Devuelve: *Promise[object]*

*   `getAllReleases({ user_id, limit, page })`
    *   Recupera los lanzamientos de un usuario dado.
    *   Parámetros:
        *   `user_id`: *String* El ID del usuario.
        *   `limit`: *Number* El número de lanzamientos a recuperar por página.
        *   `page`: *Number* El número de página a recuperar.
    *   Devuelve: *Promise[object]*

*   `getReleaseData(id: String)`
    *   Recupera los datos de un lanzamiento concreto.
    *   Parámetros:
        *   `id`: *String* El ID del lanzamiento.
    *   Devuelve: *Promise[object]*

*   `putRelease(release)`
    *   Crea/actualiza un lanzamiento.
    *   Parámetros:
        *   `release`: *Object* El objeto de lanzamiento a crear/actualizar.
    *   Devuelve: *Promise[object]*

*   `deleteRelease(release_id)`
    *   Elimina un lanzamiento.
    *   Parámetros:
        *   `release_id`: *String* El ID del lanzamiento a eliminar.
    *   Devuelve: *Promise[object]*

### Métodos relacionados con la biblioteca

*   `getMyLibrary({ limit = 100, offset = 0, order = "desc", kind })`
    *   Recupera la biblioteca de música del usuario.
    *   Parámetros:
        *   `limit`: *Number* El número de elementos a recuperar.
        *   `offset`: *Number* El offset desde el que empezar a recuperar.
        *   `order`: *String* El orden para clasificar los elementos ("asc" o "desc").
        *   `kind`: *String* Filtra la biblioteca por tipo (p. ej. "track", "release").
    *   Devuelve: *Promise[object]*

*   `toggleItemFavorite(type, item_id, to)`
    *   Alterna el estado de favorito de un elemento de la biblioteca.
    *   Parámetros:
        *   `type`: *String* El tipo de elemento ("track", "release", etc.).
        *   `item_id`: *String* El ID del elemento.
        *   `to`: *Boolean* Si añadir a favoritos (true) o quitarlo (false).
    *   Devuelve: *Promise[object]*

*   `isItemFavorited(type, item_id)`
    *   Comprueba si un elemento está marcado como favorito en la biblioteca.
    *   Parámetros:
        *   `type`: *String* El tipo de elemento ("track", "release", etc.).
        *   `item_id`: *String* El ID del elemento.
    *   Devuelve: *Promise[object]*

### Otros métodos

*   `getRecentyPlayed(params)`
    * Recupera las pistas reproducidas recientemente.
    * Parámetros:
        * `params`: *Object* Parámetros adicionales para la petición.
    * Devuelve: *Promise[object]*

*   `search({ keywords, limit, offset })`
    * Busca elementos de música.
    * Parámetros:
        *   `keywords`: *String* Las palabras clave de búsqueda.
        *   `limit`: *Number* El número de resultados a devolver.
        *   `offset`: *Number* El offset desde el que empezar la búsqueda.
    *   Devuelve: *Promise[object]*

### Alias

*   `toggleItemFavourite`: Alias de `toggleItemFavorite`.
*   `isItemFavourited`: Alias de `isItemFavorited`.
