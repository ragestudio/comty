`comty.js` is the official JavaScript client for the Comty API.

It bundles an HTTP client with an automatic auth pipeline, an autonomous auth manager, an agnostic storage engine, a self-managed websocket manager and typed wrappers for the backend endpoints.

## Install

```bash
pnpm add comty.js
```

## Quick start

```ts
import { authManager } from "comty.js"
import UsersModel from "comty.js/endpoints/user"

// load the persisted session and start the auto refresh
await authManager.start()

const user = await UsersModel.self()
```

## Architecture

### Core

| Module | Description |
| --- | --- |
| [Client](core/client) | HTTP client and request pipeline |
| [Session](core/session) | Current session and token access |
| [Storage](core/storage) | Agnostic storage engine (memory, cookies, expo secure store) |
| [Authentication](core/authentication) | Autonomous auth manager, auto refresh and state store |
| [Realtime](core/realtime) | Self-managed websocket manager |

### Endpoints

Typed wrappers around the backend endpoints, one singleton per domain. See [Endpoints](endpoints).

### Addons

Register third party addons that extend the endpoint results. See [Addons](addons).

## Importing

The package exposes an `exports` map, so both the barrel and individual subpaths are available:

```ts
import { Client, session, authManager } from "comty.js"

import client from "comty.js/client"
import { authManager } from "comty.js/auth"
import useAuth from "comty.js/auth/use"
import WebsocketManager from "comty.js/realtime"
import UsersModel from "comty.js/endpoints/user"
import use from "comty.js/hooks/use"
import measurePing from "comty.js/utils/measurePing"
```
